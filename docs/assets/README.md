# Demo assets

The root `README.md` links to GIFs in this folder that aren't recorded yet. Add them here with these exact filenames and they'll show up automatically — no other change needed:

- `demo-tracking.gif` — upload a video and watch player/ball tracking overlays render
- `demo-actions.gif` — a rally with action classifications (serve/set/spike/dig/block) called out live
- `demo-stats.gif` — the per-video or per-team stats dashboard
- `frontend-videos.gif` — the Videos page: upload flow + stage progress
- `frontend-teams.gif` — the Teams page: roster, win/loss, win-rate radar
- `frontend-players.gif` — the Players page: per-player stats across videos
- `frontend-scoring.gif` — Setup tab: scoring mode + scoreboard OCR region picker
- `frontend-court-calibration.gif` — Setup tab: clicking court corners/net points
- `frontend-player-id.gif` — Setup tab: naming/merging detected players

Keep each under a few MB (crop tightly, ~5-10s loop, reduce fps/colors) so the README stays fast to load.
